# 📝 Formulário de Matrícula - Estrelas do Amanhã

Uma interface web moderna e acolhedora para o processo de matrícula escolar, focada em usabilidade e design limpo.

## 🚀 Sobre o Projeto
Este projeto consiste na página de cadastro para a escola de educação infantil "Estrelas do Amanhã". O layout foi projetado para ser intuitivo, dividindo a tela entre o formulário de dados da criança e uma seção visual informativa, garantindo uma experiência agradável para os pais.

## 🛠️ Tecnologias
*   **HTML5** (Estruturação semântica)
*   **CSS3** (Estilização, Flexbox/Grid e variáveis de cor)

## ⚠️ Nota de Autoria
**Este código foi escrito 100% sem o uso de Inteligência Artificial.** Todo o desenvolvimento, estruturação e estilização foram realizados manualmente, demonstrando domínio das tecnologias web.

## 🔧 Como visualizar
Basta clonar o repositório e abrir o arquivo `index.html` no seu navegador.
